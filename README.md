# ÉCRU — Atelier Commerce

A premium, editorial e-commerce frontend. Original brand, original code, original content.

## Stack
- React 18 + TypeScript + Vite
- Tailwind CSS
- GSAP + ScrollTrigger
- Lenis smooth scroll
- Framer Motion (component transitions)
- Zustand (cart state)

## Run
    npm install
    npm run dev

## Build
    npm run build
    npm run preview

## Structure
- src/components — UI primitives, layout, product components
- src/sections — home page sections
- src/pages — routed pages
- src/data — product / collection / site data (replace freely)
- src/store — Zustand stores
- src/hooks — Lenis, magnetic, mobile detection
- src/lib — utilities

Replace src/data/* and image URLs to rebrand.
